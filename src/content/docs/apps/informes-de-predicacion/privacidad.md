---
title: Política de Privacidad
description: Política de privacidad de la app Informes de Predicación.
---

**Última actualización:** 27 de agosto de 2026

Esta política describe cómo se recopila, utiliza y protege la información en el sistema de **Informes de Predicación**, compuesto por un formulario web para el envío de informes mensuales y una aplicación móvil para la gestión y generación de resúmenes.

---

## 1. Información general y almacenamiento

El sistema opera utilizando únicamente la infraestructura de **Google Firebase**:

- **Firebase Cloud Firestore** — almacenamiento y sincronización de datos.
- **Firebase Authentication** — autenticación de usuarios.

Ningún dato personal o de informes se vende, comparte, transfiere ni se utiliza para fines comerciales, publicidad o análisis de terceros. La información se usa exclusivamente para fines organizativos y administrativos dentro de la congregación.

---

## 2. Datos recopilados según la plataforma

### Plataforma web (publicadores)

Datos ingresados voluntariamente en el formulario:

- Nombre completo
- Mes y año del informe
- Detalles del informe: horas dedicadas, cursos bíblicos, confirmación de participación en la predicación, y observaciones adicionales (si aplica)

### Aplicación móvil (encargados de grupo)

- **Autenticación y configuración:** datos necesarios para conectar con el proyecto de Firebase asignado.
- **Archivos locales:** los PDF generados por la aplicación se almacenan localmente en el dispositivo del encargado para su visualización y consulta.

:::note
No nos hacemos responsables por el uso que se le dé a los documentos generados desde la aplicación.
:::

---

## 3. Uso de la información

Los datos recopilados se utilizan exclusivamente para:

1. Generar los resúmenes mensuales del grupo de predicación.
2. Crear informes acumulados en formato PDF para el archivo de la congregación.
3. Permitir a los encargados realizar correcciones o actualizaciones en los registros mensuales.

---

## 4. Almacenamiento local y permisos en la app

La aplicación móvil puede requerir los siguientes permisos:

- **Almacenamiento / gestión de archivos:** necesario para guardar los PDF generados y permitir compartirlos.
- **Acceso a red (Internet):** necesario para conectar la app con Firebase y sincronizar los informes en tiempo real.

---

## 5. Seguridad de los datos

- Toda la comunicación entre la web, la aplicación móvil y la base de datos se realiza mediante conexiones cifradas (HTTPS/TLS).
- El acceso a la base de datos en Firebase está restringido mediante reglas de seguridad configuradas para el proyecto.

---

## 6. Retención y eliminación de datos

- **Retención:** los informes se conservan en la base de datos durante el tiempo necesario para la elaboración de estadísticas organizativas.
- **Solicitud de eliminación:** cualquier publicador puede solicitar la revisión, corrección o eliminación de sus registros a través del encargado de su grupo o del administrador del proyecto.
