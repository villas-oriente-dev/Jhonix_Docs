**Last updated:** August 27, 2026

This policy describes how information is collected, used, and protected in the **Field Service Reports** system, which consists of a web form for submitting monthly reports and a mobile application for managing and generating summaries.

---

## 1. General Information and Storage

The system operates using solely **Google Firebase** infrastructure:

- **Firebase Cloud Firestore** — data storage and synchronization.
- **Firebase Authentication** — user authentication.

No personal or report data is sold, shared, transferred, or used for commercial, advertising, or third-party analytics purposes. The information is used exclusively for organizational and administrative purposes within the congregation.

---

## 2. Data Collected by Platform

### Web platform (publishers)

Data voluntarily entered in the form:

- Full name
- Report month and year
- Report details: hours spent, Bible studies, confirmation of participation in field service, and additional remarks (if applicable)

### Mobile application (group overseers)

- **Authentication and configuration:** data required to connect to the assigned Firebase project.
- **Local files:** PDFs generated by the application are stored locally on the overseer's device for viewing and reference.

:::note
We are not responsible for how the documents generated from the application are used.
:::

---

## 3. Use of Information

The collected data is used exclusively to:

1. Generate monthly summaries for the field service group.
2. Create compiled reports in PDF format for congregation records.
3. Allow overseers to make corrections or updates to monthly records.

---

## 4. Local Storage and App Permissions

The mobile application may require the following permissions:

- **Storage / File management:** required to save generated PDFs and allow sharing them.
- **Network access (Internet):** required to connect the app with Firebase and synchronize reports in real time.

---

## 5. Data Security

- All communication between the web, the mobile application, and the database is carried out over encrypted connections (HTTPS/TLS).
- Access to the Firebase database is restricted through security rules configured for the project.

---

## 6. Data Retention and Deletion

- **Retention:** reports are kept in the database for the time necessary to compile organizational statistics.
- **Deletion requests:** any publisher may request the review, correction, or deletion of their records through their group overseer or the project administrator.
