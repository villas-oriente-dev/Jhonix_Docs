## Design

The design approach prioritizes clarity and functionality over decoration.
Every visual decision has a purpose.

### Principles

- **Minimalism** — clean interfaces, without unnecessary elements. Only what the user needs to see.
- **Neutral colors** — reduced palettes with a defined accent color for the site. In Mobile Apps, use of device colors.
- **Typography** — readable fonts with a clear hierarchy.
- **Iconography** — exclusively [Material Icons](https://fonts.google.com/icons) from Google Fonts. No emojis.
- **Animations** — subtle and intended to make the user experience pleasant.

### In mobile applications

Android apps are developed with **Jetpack Compose**, which natively implements
**Material Design 3**. M3 components fit directly with the minimalist philosophy
applied across the JHONIX Apps ecosystem.
